# 한전 NDIS데이터관리원 필기 대비

한국전력공사 2026년도 NDIS데이터관리원 2차전형(필기) 대비 예상문제 111문항.

- `index.html` — 표지 (D-Day, 시험정보, 공부 순서)
- `quiz.html` — 문제 풀기 (과목별 필터 / 즉시 채점 / 오답 재풀이 / 요약시트 / 4일 계획)
- `answers.html` — 정답 및 상세해설 (111문항 전문, 비전공자 기준 풀이)

## 배포 (GitHub Pages)

1. 새 저장소 생성 (예: `ndis`) — Public
2. 이 폴더의 3개 파일 업로드
3. Settings → Pages → Source: `Deploy from a branch` / Branch: `main` / 폴더: `/ (root)` → Save
4. 1~2분 뒤 `https://<사용자명>.github.io/ndis/` 접속

## 안내

필기는 자체출제 비공개 시험이라 공개 기출이 없습니다. 공고 출제범위, 필수자격 난이도,
붙임5 직무설명자료를 근거로 작성한 예상문제이며 실제 시험지의 재현이 아닙니다.
